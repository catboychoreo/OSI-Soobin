# OS(oobin)I Model

An interactive visual novel game that teaches the OSI (Open Systems Interconnection) network model through narrative and minigames. Built in vanilla HTML, CSS, and JavaScript, using a custom dialogue engine.

The game currently covers layers 1-4 of the model with a few minigames! The most notable one makes the player manually decrypt a message using a casear cipher. Layers 5-7 may come eventually.

To play, download the file and open osi.html in your browser.
